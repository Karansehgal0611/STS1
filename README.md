# STS1 – 5th Semester Java Practice Repository

This repository contains Java implementations of various algorithms and data structures, developed as part of the 5th Semester STS (Software Technical Skills) coursework. It serves as a practical resource for understanding and applying core concepts in computer science.

---

## 📁 Repository Structure

The repository includes the following Java files:

### 🔢 Mathematical Algorithms
- `ChineseRem.java` – Chinese Remainder Theorem implementation.
- `Eulerphi.java` – Euler's Totient function computation.
- `Karatsuba.java` – Karatsuba algorithm for fast multiplication.

### 🔠 String Algorithms
- `Manacher.java` – Manacher's algorithm for longest palindromic substring.
- `Manacher1.java` – Alternative implementation of Manacher's algorithm.
- `strobo.java` – Strobogrammatic number checker.
- `lexicographically.java` – Lexicographical string comparison.

### 📊 Array and Sequence Algorithms
- `AliceAppleTree.java` – Problem-solving related to tree structures.
- `BinaryPalindrome.java` – Binary palindrome checker.
- `Hourglass.java` – Hourglass sum calculation in 2D arrays.
- `Leader.java` – Finding leaders in an array.
- `LongSequence.java` – Longest sequence finder.
- `RotateAnArray.java` – Array rotation algorithms.
- `maxEqui.java` – Maximum equilibrium index finder.
- `weightedString.java` – Weighted string analysis.

### 📦 Stack Implementations
- `minStack.java` – Stack with minimum element retrieval.

### 📌 Miscellaneous
- `Recursive.java` – Various recursive function implementations.
- `SegmentedSeive.java` – Segmented Sieve of Eratosthenes.
- `Simpleseive.java` – Simple Sieve of Eratosthenes.
- `Example.java`, `Example2man.java` – Example programs for practice.
